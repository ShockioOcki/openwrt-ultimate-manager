# Незавершённая системная тема OUM

`luci-theme-oum/` и `install-theme-dev.sh` сохранены для отдельной доработки.
Они не входят в релизный архив и не устанавливаются вместе с проектом.
Ручная установка экспериментальной темы не является частью обычного обновления OUM.

Стандартный LuCI оформляет Proton2025. В `luci-app-oum` остаётся отдельная
оболочка `oum-app`, используемая только маршрутами `/oum/`. Она не регистрируется
в списке системных тем. Общие базовые стили сохранены ради совместимости страниц
OUM; модули оформления сетевых таблиц, журналов и других страниц LuCI исключены.
