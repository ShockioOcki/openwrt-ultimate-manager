# Проверка чистой установки OUM 0.0.1 — Xiaomi CR6606

Дата: 2026-09-16. Роутер предоставлен как CR6606; установленная прошивка сообщает `Xiaomi Mi Router CR6609`, `xiaomi,mi-router-cr6609`. Совпадение аппаратной модели с профилем прошивки отдельно не подтверждалось.

- OpenWrt 25.12.5, ядро 6.12.94, `ramips/mt7621`, `mipsel_24kc`.
- Установлена сборка `0.0.1+322f7885a399` через штатный `--install`.
- Перед установкой сохранены sysupgrade backup, перечень пакетов и контрольные суммы network/wireless/dhcp/firewall. Резервная копия хранится локально вне репозитория; в релиз не включается.
- Проверка SHA-256 payload и установка завершились с кодом 0. Автоматически установлены 28 пакетов с зависимостями, включая русские переводы. Свободное место после стабилизации overlay — около 46.8 МиБ.
- USB отсутствует. USB-драйверы, Aria2, AriaNg, ksmbd, minidlna, comgt и luci-proto-3g не установлены.
- Найден и устранён лишний базовый пакет `luci-proto-3g`: теперь он устанавливается менеджером модема только при настройке PPP-модема. Проверены автоматические зависимости для случая уже установленного comgt.
- Контрольные суммы network/wireless/dhcp/firewall после установки совпадают с исходными.
- Службы rpcd/uhttpd работают, объект RPC `oum` зарегистрирован. Методы status/settingsStatus/usbStorageStatus возвращают корректный JSON; USB определяется как отсутствующий.
- В каталоге форм только пять `*-v1.js`, QR-библиотека и лицензия.
- Вход в браузере работает, мастер первого запуска открывается в отдельной центральной карточке. Другие страницы до завершения мастера штатно перенаправляются на setup.
- На самом роутере прошли тесты конвертера подписок/AWG/URI, policy YAML и backup codec. Дополнительные Ruby-модули сверх штатных зависимостей не потребовались. Временные синтетические тестовые файлы удалены.

## Ограничения и оставшиеся проверки

- VPN-комплекты текущей версии предназначены для ARM64; платформа MIPS не поддерживается существующим механизмом переключения движков. Несовместимые комплекты не устанавливались.
- Радиодрайвер заявляет Mesh и WISP, но проверенного wpad Mesh-комплекта для MIPS в этой версии нет.
- Мастер завершён пользователем (`setup_complete=1`). После него изменился wireless; network/dhcp/firewall сохранили исходные контрольные суммы. Пользователь повторно вошёл после настройки пароля.
- Проверены загрузка главной, настроек, родительского контроля и справки, открытие Wi-Fi QR. Для главной и настроек проверена мобильная ширина 390 px: горизонтального переполнения и не загрузившихся изображений не обнаружено. Настройки во время этих проверок не сохранялись.
- RPC сообщает `engines.supported=false`; это подтверждает отсутствие комплекта движков для данной архитектуры. Проверка загрузки страницы не равнозначна проверке действия каждой функции.
- Успешная базовая установка не является подтверждением полной функциональности OUM на MT7621. Коммит по условию полного успешного теста пока не выполнен.

## Возврат согласованной темы

После замечания пользователя обнаружен отложенный редизайн в исходниках, попавший в установщик. Восстановлен принятый stock-layout.css из резервной копии, отключён экспериментальный UX-скрипт. До замены сохранена копия файлов на роутере в `/etc/oum/rollback/theme-release-repair/` и локально вне репозитория.

Проверены карточки настроек на мобильном, компактная панель VPN, сетка форм на десктопе, светлая/тёмная тема; таблица сетевых интерфейсов и мобильный диалог lan (366 px при экране 390 px, без горизонтального переполнения). Настройки сети не сохранялись. Проверка не подтверждает работоспособность VPN на MIPS.

Тест общей CSS-совместимости выполнен отдельно на локальном синтетическом DOM: hidden-поля и таблицы проходят, неактивные вкладки не проходят на обеих ширинах, custom output не проходит на десктопе. Стороннее приложение на роутере не проверено: оно не установлено. Полная совместимость темы пока не заявляется.
