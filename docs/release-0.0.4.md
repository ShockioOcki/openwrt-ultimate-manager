# OUM 0.0.4

Установка и обновление OUM теперь автоматически включают ускорение трафика вместе с FIX Flow Offloading для Zapret. Ранее ускорение зависело от настроек прошивки, а фикс применялся только при запуске Zapret через OUM.

## Изменения

- Программное ускорение включается при установке. Для MediaTek MT7621, MT7622, MT7981, MT7986 и MT7988 также включается аппаратное ускорение; на остальных платформах используется программное.
- Модуль `kmod-nft-offload` устанавливается из репозитория текущей прошивки с проверкой совместимости ядра средствами apk.
- FIX Zapret сразу добавляет порог 30 пакетов исходного направления перед передачей соединения в ускорение. Установка самого Zapret для этого не требуется.
- Настройки firewall и его шаблон сохраняются перед изменением. Ошибка применения, проверки или перезагрузки вызывает восстановление исходных файлов и попытку перезагрузить восстановленный firewall.
- Повторный запуск с уже настроенными параметрами и фиксом не перезагружает firewall. Несохранённые изменения firewall необходимо применить или отменить перед установкой; установщик их не коммитит и не отбрасывает.
- Все исправления 0.0.3 — иконки, окно активации и SMB-адрес — включены.

## Установка

Требуется OpenWrt 25.12.x. Подключитесь к роутеру по SSH под root:

```sh
wget -O /tmp/oum-install.sh "https://github.com/ShockioOcki/openwrt-ultimate-manager/releases/download/v0.0.4/oum-install.sh" &&
sh /tmp/oum-install.sh
```

Выберите пункт 1 для установки или обновления. На уже установленной 0.0.3 также можно проверить обновления в OUM. Контрольная сумма установщика опубликована в `SHA256SUMS`.

## Проверки

Автотесты выполняют настоящий скрипт настройки и FIX Zapret с изолированными UCI и firewall: чистая установка, выбор аппаратного/программного режима, повторный запуск, уже исправленный шаблон, ошибки commit/check/reload, неизвестный шаблон и сохранность несохранённых пользовательских правок. Проверяется также включение скрипта и зависимости в собранный установщик.

Аппаратная проверка автоматического включения ускорения и чистая установка полного выпуска 0.0.4 на момент публикации ещё не выполнены. Наличие настройки аппаратного ускорения не означает ускорение всего VPN-трафика; фактическая работа зависит от драйвера и маршрута соединения.
