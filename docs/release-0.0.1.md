# OUM 0.0.1 — подготовка выпуска

Статус: локальная сборка для проверки перед публикацией. Коммит, тег и GitHub Release пока не созданы. В этом аудите интерфейс, тема и набор пользовательских функций не менялись.

## Автоматическая установка

| Этап | Пакеты и условия |
| --- | --- |
| Установка OUM | LuCI, RPC, HTTP, сетевые утилиты, PPPoE, Ruby/YAML, QR и русский язык базового LuCI, firewall и менеджера пакетов. Установленный `dnsmasq-full` сохраняется. |
| Wi-Fi MT7981 / MT7986 | Драйвер MT7915 и firmware выбранного SoC из штатных репозиториев прошивки. Принудительная установка несовместимых kmod не используется. |
| USB-контроллер MediaTek | `kmod-usb3`, `kmod-usb-xhci-mtk` только для включённого контроллера из Device Tree; наличие драйвера для определения оборудования не требуется. Отключённые узлы и их отключённые родители исключаются. |
| Нет USB-контроллера | Установщик не запрашивает USB-пакеты. |
| Настройка подключённого USB-накопителя | `block-mount`, USB Storage/UAS/SCSI, ext4, e2fsprogs, parted. Нет подключённого накопителя — пакеты не устанавливаются. Само подключение диска не запускает форматирование или дополнительные службы. |
| Включение файлового доступа | `ksmbd-server`, только при наличии смонтированного управляемого диска. |
| Включение загрузок | `aria2` и `ariang`, только при наличии смонтированного управляемого диска. |
| Включение медиасервера | `minidlna`, только при настройке этой функции. |
| Включение сортировки медиа | Python и необходимые модули, только при настройке сортировки. |
| USB-интернет | Драйверы RNDIS/CDC/QMI/MBIM/NCM/PPP подготавливаются существующим менеджером при настройке подключённого устройства. |
| VPN | Существующие установщики ставят выбранный движок и зависимости по запросу. `tcping` устанавливается с PassWall из закреплённого источника с SHA-256, а не из штатного feed. Podkop включает русский перевод. |
| Mesh | Используется существующий совместимый комплект wpad; при несовпадении архитектуры/версии hostapd установка останавливается до замены пакетов. |

Уже установленные приложения не удаляются при отключении USB или обновлении OUM. Для автоматической загрузки зависимостей нужен рабочий интернет и доступ к репозиториям.

## Исправления аудита

- Убран `tcping` из базовых зависимостей: в штатном feed OpenWrt 25.12.5 проверяемого роутера его нет. Он нужен только PassWall, который уже устанавливает его автоматически.
- Добавлено определение включённого USB-контроллера до установки драйвера.
- Подготовка USB не ставит пакеты без контроллера/накопителя, не повторяет установку готового комплекта и не сообщает успех при исчезнувшем диске.
- Закрепление системных зависимостей VPN сохраняет вариант `dnsmasq-full` и больше не требует конкретного ABI-имени `libubus20251202`; библиотеку выбирает APK по зависимостям `ubus`.
- Версия приложения и CLI: 0.0.1. Установщик: `0.0.1+<идентификатор сборки>`. Версия независимого пакета темы не изменялась.
- Идентификатор учитывает payload и код установщика. Порядок файлов, владельцы и времена архива нормализованы для воспроизводимой сборки.

## Перед публикацией

1. Прогнать установку на чистой совместимой прошивке с интернетом: текущий роутер уже содержит зависимости и не заменяет такой тест.
2. На оборудовании без USB подтвердить отсутствие USB-пакетов; на оборудовании с USB проверить подготовку диска и включение выбранных служб без ручных команд установки. Не форматировать рабочий накопитель для проверки.
3. Отдельно подтвердить другие модели/SoC. Наличие ветки MT7986 не означает аппаратную проверку; универсальная совместимость со всеми роутерами не заявляется. Mesh зависит от доступного проверенного комплекта; AWG — от наличия пакета под ядро прошивки.
4. Согласовать итоговый diff, затем коммит/тег 0.0.1 и оформление GitHub Release. До публикации ссылка установки в README указывает на прежнюю опубликованную ветку, а не на эту локальную сборку.

## Чистота релизного пакета

- Упаковка содержит только активные `dashboard-v1`, `settings-v1`, `first-run-v1`, `parental-v1`, `help-v1`, общий генератор QR и его лицензию. Старые версии и старый `view/oum/oum.css` исключаются на этапе сборки, исходные наработки не удаляются из репозитория.
- Ссылки активных стилей/скриптов темы используют `v=1&h=<хеш содержимого>` для обновления кеша при повторной установке версии 1. Поведение форм при переименовании не меняется. При обновлении старые версии форм удаляются с роутера после копирования новых; резервная копия создаётся до установки.
- Проверен распакованный установщик: приватные ключи, персональная подписка и значения ключей/адреса сервера из предоставленного AWG-конфига не обнаружены. Сам AWG-конфиг в сборку не входит.
- Единственный включённый SSH-ключ — **публичный ключ удалённой поддержки**, оставленный по явному согласованию. Приватная часть не включается.
- Сборка автоматически останавливается при обнаружении литералов секретов, посторонних конфигураций роутера или неожиданных ключевых файлов. Это дополнительная проверка, не гарантия распознавания любого возможного способа сокрытия секретов.
- Тестируется фактический архив: ссылки меню, комплект активных форм, неизменность CSS/логики форм, наличие ресурсов и отказ проверки на подставленном приватном ключе без вывода самого секрета.
- Исправлено копирование локальной QR-библиотеки: раньше файл присутствовал в payload, но установщик пропускал его при копировании на роутер.

## Дополнительная проверка на чистом MIPS-роутере

Базовая установка на Xiaomi CR6606 (профиль прошивки CR6609), OpenWrt 25.12.5 / MT7621 прошла успешно. Подробности и ограничения — [test-cr6606-0.0.1.md](test-cr6606-0.0.1.md). Найденный лишний базовый `luci-proto-3g` перенесён в автоматическую подготовку PPP-модема. Первый запуск завершён пользователем, основные страницы и Wi-Fi QR проверены. VPN/Mesh-комплекты для MIPS пока не поддерживаются.

- `stock-layout.css` восстановлен из сохранённой рабочей копии 15 сентября. SHA-256: `863845c21e0e3844a7bd200cf020a73aa614237ee8b4450e1354af0d3b08fcc6`. Тест релизного пакета закрепляет эту версию.
- Экспериментальный `oum-theme-ux.js` исключён из подключения и релизного пакета. Устранены навязанные плоский список настроек на десктопе и полноэкранные мобильные панели.
- Сохранены последующие исправления боковой панели, тёмных иконок и логики форм. Исправлена повреждённая ссылка cascade.css.
- Сборка после исправления: `0.0.1+7f7005b1fd8a`. Синтаксис, контракты, аудит секретов и проверка фактического payload прошли.
- Проверка общей CSS-совместимости на локальной синтетической странице не прошла полностью: неактивная вкладка видна на 390/1440 px; нестандартная панель не занимает всю ширину на 1440 px. Скрытые поля и native-table прошли на обеих ширинах. Это не проверка авторизованной сторонней программы; сторонние приложения на тестовом MIPS-роутере не установлены. Эти ограничения требуют отдельной диагностики перед заявлением полной совместимости.
- На роутере обновлены только файлы темы и ссылки ресурсов в активных формах; полный установщик повторно не запускался, метаданные установленной версии сохранены.
