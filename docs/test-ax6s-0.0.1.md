# AX6S: проверка OUM 0.0.1

Дата: 2026-09-16. Xiaomi Redmi Router AX6S, MT7622, OpenWrt 25.12.5, aarch64_cortex-a53.

- Чистая установка сборки 0.0.1+7f7005b1fd8a завершилась успешно; автоматически добавлены 27 пакетов, включая русский язык.
- До установки сохранена конфигурация вне репозитория. network/wireless/dhcp/firewall после установки совпали с исходными контрольными суммами.
- Пользователь завершил первый запуск. Исправлена подсказка с фиксированным IP: мастер сохраняет LAN-адрес, теперь сообщает текущий адрес панели.
- Установлен PassWall 26.5.11-r1 с Xray 26.5.9 штатным менеджером движков. Установка завершилась успешно; Xray запускается для вывода версии. Туннель оставлен выключенным. Свободно около 44.8 МиБ overlay.
- При отсутствии USB-порта раздел USB скрыт на мобильном и десктопе; USB-вариант WAN также отсутствует. Наличие пустого USB-порта не скрывает настройки на других моделях.
- Последняя сборка с этими исправлениями: 0.0.1+5674a8cac588. На роутере исправления форм применялись отдельно; метаданные базовой установки не менялись.

Остаются: визуальная проверка сторонних VPN-форм, работа туннелей и переключение между движками на AX6S. Общие ограничения CSS описаны в release-0.0.1.md. USB на этом устройстве не проверялся. Это рабочая версия для дальнейшего тестирования, не подтверждение всех функций.
