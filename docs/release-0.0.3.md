# OUM 0.0.3

Выпуск 17 сентября 2026 года исправляет ошибки интерфейса, обнаруженные при ручной проверке 0.0.2 на RAX3000M.

## Изменения

- Иконки главной страницы и сервисов устанавливаются вместе с приложением. Страница обращается к ресурсам приложения, поэтому иконки доступны после чистой установки без экспериментальной темы OUM и без старого браузерного кэша.
- При импорте и активации подписки на компьютере открывается окно прогресса с этапами загрузки, импорта и активации. Закрытие окна не прерывает отслеживание операции и не разрешает повторный запуск до её завершения.
- Исправлен адрес сетевой папки: `smb://<LAN-IP>/OUM`.
- Номер версии увеличен до 0.0.3, чтобы проверка обновлений предлагала исправления пользователям 0.0.2.

## Установка

Требуется OpenWrt 25.12.x. Подключитесь к роутеру по SSH под root:

```sh
wget -O /tmp/oum-install.sh "https://github.com/ShockioOcki/openwrt-ultimate-manager/releases/download/v0.0.3/oum-install.sh" &&
sh /tmp/oum-install.sh
```

Установщик включает Proton2025 и сохраняет существующие настройки при обновлении. Экспериментальная тема OUM не входит в пакет. Контрольная сумма опубликована в `SHA256SUMS` рядом с установщиком.

## Проверки

- Проверка содержимого собранного установщика выполняет установку иконок в пустую папку и проверяет наличие и корректность SVG всех иконок главной страницы, включая динамические значки сервисов.
- Автотесты проверяют окно активации на компьютере и телефоне, этапы операции, ошибки, скрытие окна, защиту от повторного запуска и формат SMB-адреса.
- На RAX3000M применён патч интерфейса; главная страница и все 40 SVG проверены по HTTP с сопоставлением содержимого исходникам.

Повторная чистая установка полного выпуска 0.0.3 на роутере на момент публикации ещё не проверена. Cudy TR3000 на оборудовании не тестировался. Ограничения поддержки архитектур предыдущего выпуска сохраняются.
