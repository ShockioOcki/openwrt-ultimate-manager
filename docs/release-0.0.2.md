# OUM 0.0.2

Выпуск 17 сентября 2026 года. Установщик: `dist/oum-install.sh`.
GitHub Release: [v0.0.2](https://github.com/ShockioOcki/openwrt-ultimate-manager/releases/tag/v0.0.2).

## Изменения

- Установщик включает Proton2025 1.4.1 и согласованный профиль оформления. Профиль применяется один раз; дальнейшие обновления сохраняют пользовательские настройки Proton.
- Переключатель светлой/тёмной темы OUM синхронизирует режим с Proton.
- Экспериментальная системная тема OUM перенесена в `experimental/` и не входит в установщик. Страницы OUM используют собственную оболочку; стандартный LuCI и сторонние приложения — Proton. Ранее установленные файлы экспериментальной темы сохраняются в архиве на роутере.
- Проверка обновлений сначала получает сведения о новой версии. Установка предлагается только при наличии более новой версии и требует подтверждения.
- Старые страницы из кэша при вызове обновления без проверенной версии выполняют только проверку. Адреса активных модулей меняются вместе с их содержимым.
- В интерфейсе отображается короткая версия, например `0.0.2`. Внутренний идентификатор сборки сохраняется для различения установщиков.
- Исправлено выравнивание кнопки применения родительского контроля.

## Проверки и границы

Проверяются синтаксис, содержимое установщика и SHA-256, отсутствие экспериментальной темы в пакете, включение Proton, повторная установка без сброса настроек, архивирование старой темы, сценарии проверки/предложения обновлений и контракты приложения.

На AX6S изменения интерфейса и RPC установлены отдельно с резервной копией: проверка обновлений и загрузка страниц OUM, стандартного LuCI и PassWall проверены. Полный установщик 0.0.2 и чистая установка этой версии на роутере ещё не запускались. Визуальная проверка текущих изменений ограничена недоступностью инструмента управления браузером.

Аппаратные проверки предыдущего выпуска: [AX6S](test-ax6s-0.0.1.md), [CR6606](test-cr6606-0.0.1.md). Они не заменяют проверку чистой установки 0.0.2. Требование OpenWrt 25.12 и ограничения поддержки архитектур сохраняются.
