# Россия: выборочный VPN с приоритетом игр

Правила PassWall применены на RAX3000M. OpenClash использует новую схему при генерации OUM-профиля; установленный движок не менялся. Тема и механизм смены движков не изменены.

- Локальная сеть и GearUP напрямую.
- Discord — отдельное VPN-правило выше игровой категории.
- Игровые домены напрямую, выше общего списка ограничений.
- Российские сервисы и .ru/.su/.рф напрямую.
- Регионально ограниченные сервисы и общий список ограниченных доменов через выбранную ноду.
- Прочие домены и IP напрямую. Широких VPN-правил для ASN/облачных сетей нет.
- PassWall: перехватываются совпадения shunt; неизвестные игровые IP не направляются в Xray. Убрана общая блокировка UDP/443. Прямой DNS по умолчанию, DNS ограниченных доменов через туннель.
- OpenClash: MATCH,DIRECT; DNS restricted-domains через TCP resolver #PROXY, отдельный прямой bootstrap и прямой DNS для игр/России.

## Списки

Оба адаптера используют `luci-app-oum/root/usr/share/oum/routing/`.
`restricted-domains.txt` — снимок legiz-ru/mihomo-rule-sets, commit 39570daeaea324d9e9392472db2f16129627244b, ru-bundle/rule.list.
`regional-domains.txt` — небольшой встроенный список, а не вся категория AI.
22 пересечения с установленной игровой geosite-категорией исключены из общего списка; перечень в `game-exclusions.txt`.

Общий список закреплён в этой сборке. Он НЕ обновляется автоматически ежедневно: непроверенное обновление могло бы вернуть игровые домены. При обновлении снимка нужно повторить проверку пересечений и тесты. Категорийные провайдеры OpenClash сохраняют штатное обновление; их состав может отличаться от установленной geosite PassWall. Полная побитовая идентичность категорий не заявляется.

## Проверки

- Синтаксис, converter fixtures, integration contracts, policy YAML.
- tests/test_russia_routing.rb: игровые исключения, приоритеты, прямой fallback, отсутствие широких IP-blocklists, DNS bootstrap.
- Mihomo 1.19.30: `-t` успешно проверил сгенерированный профиль. Сам OpenClash на роутере не запускался.
- Xray: сгенерированный runtime проходит `run -test` с XRAY_LOCATION_ASSET=/usr/share/v2ray.
- Диагностика: Steam, Epic, Battle.net, Xbox, Яндекс, Госуслуги и example.com DIRECT; OpenAI, Claude, Discord, YouTube VPN. Диагностика доменная, не трассировка реального игрового сеанса.
- Реальные HTTP-запросы через локальный SOCKS шунта; DNS и работа Xray проверены.

## Ограничения

Игровые магазины/авторизация с региональными ограничениями намеренно оставлены напрямую: приоритет пользователя — не отправлять игру в VPN. Для открытия такого магазина потребуется отдельное узкое решение.
Сервисы, работающие только по IP, могут потребовать отдельных адресных правил; широкие диапазоны намеренно не добавлялись. Клиентский DoH и недоступное для распознавания имя могут обойти DNS-классификацию. Фактический игровой ping и голос Discord требуют проверки с устройства игрока. VPN-IP может блокироваться самим сервисом.

До изменения сохранено: outputs/before-russia-routing/router.tar.gz; полная предыдущая копия — outputs/saved-selected-fixes-20260915-183200.

HTTP через SOCKS шунта: Steam 200, Discord 200, YouTube 200, OpenAI /v1/models 401 (без API-ключа); корневой api.openai.com вернул 421. Это проверка сетевого доступа, не авторизации аккаунтов.
