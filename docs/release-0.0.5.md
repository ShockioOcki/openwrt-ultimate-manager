# OUM 0.0.5

Исправления интерфейса и автономной работы Zapret после 0.0.4.

## Изменения

- Zapret вынесен в отдельную вкладку подключения Podkop рядом с AWG и Reality.
- В мобильном окне вкладки AWG, Reality и Zapret отображаются в один ряд.
- Добавлены выбор стратегии, автоподбор, проверка и отключение Zapret.
- Zapret может работать без активного Podkop для прямого маршрута YouTube.
- Исправлена прокрутка и свайп мобильных меню и окон.
- Исправлены адаптивная раскладка карточек главной страницы и наложение QR-кода.
- Убрана подсказка `test` из окна добавления AWG.
- QR-библиотека устанавливается с правами `0644`.

## Установка

```sh
wget -O /tmp/oum-install.sh "https://github.com/ShockioOcki/openwrt-ultimate-manager/releases/download/v0.0.5/oum-install.sh" &&
sh /tmp/oum-install.sh
```

Требуется OpenWrt 25.12.x.
