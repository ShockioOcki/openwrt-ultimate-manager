# Zapret: прогресс и Flow Offloading FIX

Изменения без коммита. Копии исходников и файлов роутера: `outputs/before-zapret-progress/`.

Активация Podkop (AWG/Reality), переключение YouTube и операции стратегий теперь показывают отдельное окно с этапами в стиле активации PassWall. Сообщения и счётчик берутся из системной задачи; проценты выводятся только при наличии счётчика. Результат закрывает пользователь. Смена движка не изменена.

`oum-zapret-manager fix` повторяет условие из системного меню закреплённого Zapret Manager (189abafd50aed17f8c7414695d0d47d129a6b0dd): `ct original packets ge 30 flow offload @ft`. SW/HW Flow Offloading остаются включены. Исходный шаблон сохраняется в `/etc/oum/rollback/zapret-flow-offloading/ruleset.before.uc`; перед reload выполняется `fw4 check`, при ошибке восстанавливается шаблон. Неизвестный формат отклоняется без изменений. Повторное применение ничего не меняет. Проверка встроена перед подготовкой Zapret и операциями стратегий. При обновлении пакета firewall4 шаблон может быть заменён; повторный запуск подготовки или проверки Zapret применит FIX заново.

На роутере правило проверено в действующем nftables. Текущая Yv08 прошла 4/4 проверки. Полный автоподбор и повторный импорт туннеля в этой проверке не запускались. Мобильное и настольное окно проверены Playwright. Маршруты игр и глобальная блокировка UDP/443 не изменялись.

Тест `tests/test_zapret_fix.py`: применение, повторный вызов, откат при ошибке fw4, неизвестный шаблон, отключённый offloading. Включён в syntax.sh.
